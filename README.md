<h1 align="center">🧠 DocChat AI</h1>

<p align="center">
  <strong>Upload documents. Ask questions. Get AI-powered answers — instantly.</strong>
</p>

<p align="center">
  A full-stack <b>Retrieval-Augmented Generation (RAG)</b> application that lets you chat with your documents using natural language. Powered by FAISS vector search and Groq's blazing-fast LLaMA 3.3 70B inference.
</p>

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 📄 **Multi-Format Upload** | Supports PDF, TXT, CSV, XLSX, DOCX, and JSON files |
| 🔍 **Semantic Search** | FAISS-powered vector similarity search across all your documents |
| 🤖 **AI Answers** | Context-aware answers generated by LLaMA 3.3 70B via Groq |
| 📚 **Source Citations** | Every answer includes references to the source documents |
| ⚡ **Incremental Indexing** | Upload new files without re-indexing everything |
| 🌙 **Dark/Light Theme** | Beautiful responsive UI with theme toggle |
| 💬 **Chat History** | Persistent conversation history within a session |
| 🗑️ **Document Management** | Upload, view, and delete documents from the sidebar |

## 🚀 Quick Start

### Prerequisites

- Python 3.10+
- A free [Groq API key](https://console.groq.com/keys)

### 1. Clone the Repository

```bash
git clone https://github.com/Aditya-yadav007/DocChat.git
cd DocChat
```

### 2. Create Virtual Environment

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirement.txt
```

### 4. Configure Environment

Create a `.env` file in the project root:

```env
GROQ_API_KEY = "your_groq_api_key_here"
GROQ_MODEL_NAME = "llama-3.3-70b-versatile"
```

> 🔑 Get your free API key at [console.groq.com/keys](https://console.groq.com/keys)

### 5. Add Documents

Place your documents (PDF, TXT, CSV, XLSX, DOCX, JSON) in the `data/` directory:

```
data/
├── pdf/          ← Put PDF files here
├── text_file/    ← Put text files here
└── uploads/      ← Files uploaded via the UI go here
```

### 6. Run the Application

```bash
python agenticrag/ui_server.py
```

Open **http://localhost:5000** in your browser 🎉

## 🖥️ Usage

### Web UI (Recommended)

1. **Upload** — Drag & drop files into the sidebar or click to browse
2. **Wait** — The system automatically chunks, embeds, and indexes your documents
3. **Ask** — Type your question in the chat input
4. **Read** — Get AI-generated answers with source citations

### CLI Mode

For quick single-query usage without the web UI:

```bash
python app.py
```

## 🛠️ Tech Stack

| Component | Technology |
|-----------|-----------|
| **LLM** | [Groq](https://groq.com/) → LLaMA 3.3 70B Versatile |
| **Embeddings** | [SentenceTransformers](https://www.sbert.net/) (all-MiniLM-L6-v2) |
| **Vector Store** | [FAISS](https://github.com/facebookresearch/faiss) (CPU, L2 similarity) |
| **Framework** | [LangChain](https://www.langchain.com/) |
| **Backend** | [Flask](https://flask.palletsprojects.com/) + Flask-CORS |
| **Frontend** | Vanilla HTML / CSS / JavaScript |

## 📝 API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| `GET` | `/` | Serve the chat UI |
| `POST` | `/upload` | Upload documents (multipart form) |
| `POST` | `/query` | Ask a question `{ "query": "..." }` |
| `GET` | `/documents` | List all indexed documents |
| `POST` | `/delete-document` | Delete a document `{ "path": "..." }` |
| `GET` | `/history` | Get chat history |
| `POST` | `/clear-history` | Clear chat history |
| `GET` | `/index-status` | Check indexing status |
